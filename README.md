Mobile:

- Navigation should become a mobile menu.

- Phone mockup should remain visible and properly scaled.

- Feature cards should become 1 or 2 columns depending on screen width.

- CTA banner should stack content/buttons.

- Testimonials should stack.

- Footer should become responsive columns.

- Nothing should overflow horizontally.
